# Side-by-side check against the real xfig (W22)

**Status:** 2026-11-01. First report (2026-10-25): 97 scenarios; round 2: 119 more; round 3 (2026-11-01, below): 210 more scenarios (40 hints with modifiers, 4 wheel, 38 Shift/Ctrl/keys, 128 on two more fixtures); none failed to run. Generated by `cargo xtask xfig-compare` (see [development.md](development.md)); the HTML with the images is `target/xfig-compare/index.html` (not committed, regenerate it). Reviewed by reading the worst-scoring and one image of each kind of scenario; the `.fig` object differences are complete for the scenarios that save.

**Setup:** real xfig 3.2.9a (`/opt/homebrew/bin/xfig`, default options, scratch `HOME`) headless on `Xvfb :77`, window 1400x1000, zoom 1.0 (80 px/in); RustFig 1400 pt wide at zoom 1, light theme, Fig (0,0) at the canvas corner. Clicks are snapped to 1/16 inch (75 Fig units) so both apps' pixel origins give the same Fig point. The RustFig window is clipped to the screen height (826 pt on the test Mac), so its bottom bar sits higher than xfig's; scores for the whole window therefore start at about 0.23 and for the canvas crop at about 0.08 for any scenario (layout, background, antialiasing): compare scores between scenarios, not with zero.

**Method:** each scenario selects a mode (xfig: mouse on the mode button as in `w_modepanel.c`'s grid, RustFig: its accessible label), clicks the same Fig points, screenshots both, and where it changes the drawing saves both `.fig` files. Text height/length are not compared (fonts), nor xfig's radius -1 against 0 on non-box polylines.

**Coverage this round:** all 40 mode buttons selected (message, mouse-button hints, indicator panel); one object drawn with each drawing mode except picture and library (dialogs only); move, copy, delete, flip up/down and left/right, rotate cw/ccw, scale, move/add/delete point, update, convert, add arrow, and the edit panel of a box, circle, polyline and text; the five menus open; the pop-ups of line width, style, fill style, pen/fill colour, depth, join, cap, grid, point position, zoom, arrow mode/type/size, text justification/angle/flags/size/font. Round 2 covers the second-level menu entries and dialogs behind them, compounds, align, join/split, chop, tangent, measure, picture objects, text editing keys and the middle/right buttons. Still not covered: Shift/Ctrl variants, other fixtures (arrows, fills, splines, metric), scroll, and the Library placement (xfig has no library loaded).
